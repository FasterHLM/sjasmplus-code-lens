# sjasmplus Code Lens

A Visual Studio Code extension for Z80 assembly written for [sjasmplus](https://github.com/z00m128/sjasmplus), aimed mainly at ZX Spectrum development.

> **Status:** early development, not published yet.

## Planned features

- Syntax highlighting for sjasmplus sources and listing files
- Code lenses with label reference counts
- Go to Definition, Find All References, Rename
- Outline view and workspace symbol search
- Hover with subroutine descriptions
- Code folding
- Completions
- Unreferenced label detection
- Awareness of sjasmplus specifics: `MODULE`, local and temporary labels, `STRUCT`, macros, `INCLUDE`
